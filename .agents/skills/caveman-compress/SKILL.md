# Caveman Compress

Compress Markdown documents and memory logs.

## Rules
1. Retain all code snippets, SQL queries, URLs, and environment variables.
2. Remove adjective fluff, lengthy introductions, and repetitive passive voice.
3. Use bullet points and compact markdown tables.
