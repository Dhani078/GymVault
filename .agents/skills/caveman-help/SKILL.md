# Caveman Help Card

| Command | Action |
| :--- | :--- |
| `/caveman lite` | Compact grammar, zero fluff |
| `/caveman full` | Caveman speech, 65% fewer output tokens (Default) |
| `/caveman ultra` | Ultra-terse bullet fragments |
| `/caveman off` | Revert to standard verbosity |
| `/caveman-commit` | High-density Conventional Commit message |
| `/caveman-review` | One-line actionable code review findings |
| `/caveman-compress` | Compact markdown and memory ledgers |
