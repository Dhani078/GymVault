# Typography Rules — Frontend God Mode

## Approved Modern Typefaces
- **Primary Display**: Plus Jakarta Sans, Syne, Outfit, Space Grotesk, Cabinet Grotesk.
- **Monospace Telemetry**: JetBrains Mono, Fira Code, Geist Mono.
- **Body & Editorial**: Plus Jakarta Sans, Satoshi, General Sans.

## Banned Defaults
- Plain default Inter without letter-spacing tuning.
- Default Roboto or Arial.
- Comic Sans, Papyrus, Times New Roman in modern interfaces.

## Letter-Spacing Matrix
- Display Headlines (`text-4xl` to `text-7xl`): `-0.025em` (Tighter tracking for architectural clarity).
- Monospace Data / Badges (`text-xs`, `text-[10px]`): `+0.05em` to `+0.1em` (Generous uppercase tracking).
- Body Text (`text-base`, `text-lg`): `-0.011em` (Optimal readability).
