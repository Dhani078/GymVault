# Frontend God Mode — Master Orchestrator

Consolidates the world's most acclaimed frontend design and engineering skills into a single high-taste execution pipeline.

## The 5 Hard Invariant Rules

These rules override everything without exception:
1. **No generic default fonts (e.g. Plain Inter)** — Use curated modern character fonts (Plus Jakarta Sans, Syne, Outfit, Cabinet Grotesk, JetBrains Mono).
2. **No generic purple-to-blue gradient on white** — Use curated chromatic palettes (Deep Obsidian `#06080D`, Electric Cyan `#00F0FF`, Golden Amber `#F59E0B`, Royal Indigo `#6366F1`).
3. **No `h-screen` on heroes** — Always use `min-h-[100dvh]` or `min-h-[92vh]`.
4. **No equal 3-card or 4-card generic feature rows** — Use asymmetric Bento grids with distinct visual archetypes (charts, live log viewer, code inspect, metric dials).
5. **No generic placeholder data ("John Doe", "Acme Corp", "$99.99")** — Always use authentic, concrete, messy, and verifiable data (`~18ms Edge Latency`, `99.972% Uptime`, real projects).

## The 24 Banned AI Tells (Anti-Slop Matrix)

1. Centered generic H1 + 2 identical stacked buttons over an empty terminal mockup.
2. Equal 3-column or 4-column card grid with generic Lucide icons inside identical grey boxes.
3. Fake "Trusted by" logos using famous trademarks (Apple, Google, Stripe) on personal projects.
4. Overly round, faked statistics ("10,000+ Users", "100%", "99%"). Use precise numbers ("1,428 active sessions", "184ms LCP", "99.972% SLO").
5. Default untinted grey drop shadows (`shadow-md`). Use color-tinted ambient diffusion shadows matching accent tokens.
6. Flat, lifeless static cards without hover micro-interactions or cursor responsiveness.
7. Jumpy, un-damped layout changes. Always use Framer Motion `layoutId` and spring physics (`stiffness: 300, damping: 30`).
8. Missing focus-visible indicators for accessibility.
9. Generic lorem ipsum or abstract corporate jargon ("Supercharge your workflow with next-gen synergy").
10. Unresponsive viewport bugs on mobile (overflow-x breaks).
11. Pure white `#ffffff` canvas with black text and no tonal hierarchy.
12. Unoptimized bundle size caused by importing entire icon packages instead of named imports.
13. Missing semantic HTML tags (`<main>`, `<header>`, `<nav>`, `<section>`, `<footer>`, `<h1>`).
14. Missing structured JSON-LD Schema markup.
15. Flash of unstyled content / broken SSR hydration.
16. Non-GPU-accelerated animations animating `top`, `left`, `margin`, or `width` instead of `transform` and `opacity`.
17. Hardcoded non-contract data types (`any`).
18. Hardcoded viewport heights without dynamic mobile browser chrome support (`100dvh`).
19. Lack of empty, loading, or error state handling.
20. Inconsistent border radii across components (mixing `rounded-sm`, `rounded-3xl`, `rounded-full` without rules).
21. Clashing low-contrast colors failing WCAG AA (minimum 4.5:1 ratio).
22. Cluttered, unaligned typography hierarchy with more than 3 distinct font sizes in one view.
23. AI-generated uncanny 3D basic primitives.
24. Monotonous card designs lacking typographic or spatial variation.

4. **Pre-flight Audit**: Check against all 24 AI tells and verify production compile.
